# 르르렌트카 마을 시안

저장소를 내려받아 이 폴더의 `index.html`을 브라우저에서 엽니다. 기존 연출과 웹 글꼴의 CDN을 불러오려면 인터넷 연결이 필요합니다.

- 배경과 차량·르르르 PNG는 `assets/`에 있습니다.
- NPC의 옷·걷기 프레임과 지도 줌·이동은 `town-runtime.js`에서 수정합니다.
- 주차 칸과 차량 배치는 `index.html`의 `SLOTS`와 `renderShop`에서 수정합니다.
- 지도 표시와 차량 색상은 `town-style.css`에서 조절합니다.

첫 차를 받고 가게에 들어가면 주차된 차량과 NPC를 볼 수 있습니다. 지도는 50~150% 범위에서 확대·축소할 수 있고, 차량을 누르면 상세 화면이 열립니다. 시설은 배경 시안입니다. Android 앱 적용과 기기 검증은 별도 작업입니다.
