# 주행 진행도 막대 시안

`index.html`을 브라우저에서 엽니다. 웹 글꼴을 불러오려면 인터넷 연결이 필요합니다.

내비 아래 한 줄 막대에 진행도와 작은 효과만 넣은 시안입니다. 네 장면이 이동 순서대로 자동 재생되고, 위쪽 버튼으로 하나씩 볼 수 있습니다.

| 장면 | 왼쪽 작은 창 | 막대 | 보여 주는 때 |
|---|---|---|---|
| 1 진행도 | 내 차가 도로를 달림 | 확인된 거리만큼 차오르고 차 아이콘이 이동 | 주차하고 앱을 열었을 때 |
| 2 휴게소 도착 | 차가 휴게소 주차 칸에 들어와 멈추고 P 표시 | 차 아이콘이 휴게소 표시까지 이동 | 휴게소에 주차했을 때 |
| 3 휴게소에서 쉬기 | 차 안에서 르르르가 졸고 Zzz | 쉰 시간이 5분까지 차오르면 "휴식 보너스 준비됨" | 휴게소에 주차해 있는 동안 |
| 4 안전운전 +머니 | 차 위로 안전 방패 | 코인이 금액 칸으로 날아가고 +120 | 주차한 뒤 결과를 볼 때 |

- 운전하는 동안에는 게임 화면을 숨겨야 해서([Pleos 심사 기준](../../contest/03_VEHICLE_API.md)) 모든 장면을 주차한 뒤 보여 주는 것을 전제로 했습니다. 주행 중 표시 허용 여부는 #81에서 확인합니다.
- 휴식 조건은 [PRD 휴식 버프](../../01_PRD.md)의 시험값(직전 1시간 이상 운전, 휴게소·졸음쉼터 5분 이상 주차, 출발하면 시작)을 따릅니다. 시안은 시간을 40배 빠르게 돌립니다.
- 거리·금액과 안전운전 판정 문구는 예시입니다. 안전운전 판정 기준과 금액은 PRD에 없어 팀 결정이 필요합니다.
- 차 그림은 픽셀 키트의 캐스퍼, `ruru-sleep.png`는 시제품의 르르르 서 있는 그림에서 눈만 감긴 모양으로 바꾼 그림입니다(48×44). 두 그림은 `index.html` 안에 들어 있습니다.
- 장면 그림과 효과는 `index.html`의 `drawRoad`·`drawRestStop`·`drawCarWindow`·`drawShield`, 장면 순서와 문구는 `SC`에서 고칩니다.
