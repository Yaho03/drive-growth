# 가게 본관 (호열 몫 ②)

2차 시안 A의 본관 생김새를 `make_building.py`가 앱 규칙(Lv1 / Lv2 이상, 지도 좌표)에 맞게 옮겨 그린다. 지도(`../map/make_map.py`)와 같은 좌표·32색 팔레트를 쓰므로, 지도를 고치면 이 스크립트도 다시 실행한다.

| 파일 | 내용 |
|---|---|
| `main_lv1.png` | 가게 Lv1 본관. 시안처럼 길고 낮은 크림색 건물, 하늘색 평지붕, 지붕 설비 상자, 남색 간판 상자, 노란 반사 유리창·문·산호색 차양·화단, 빨간 자판기, 옆면 파란 가로 창 |
| `main_lv2.png` | 가게 Lv2 이상. 정면이 길어지고, 주황 지붕 차고 별관(셔터 2개)과 설비 상자가 하나 더 생기고, 간판이 커짐 |
| `sign_mask_lv1.png`, `sign_mask_lv2.png` | 건물 그림과 같은 크기. **흰 부분(간판 정면)에만** 앱이 꾸미기 색(`ShopAppearance.accentArgb`)을 칠한다. 기본은 시안의 남색 |
| `building.csv` | 지도 원본 기준 그릴 위치(`left`,`top`)와 크기, **간판 글자 자리 네 꼭짓점**(좌하·우하·우상·좌상) |
| `preview_lv1@2x.png`, `preview_lv4@2x.png` | 지도 위 확인용 합성(가게 Lv1 / Lv4) |
| `compare_with_draft.png` | 왼쪽 2차 시안, 오른쪽 이 그림(같은 2배 배율) |

## 앱에서 그리는 법

1. `building.csv`의 `left`,`top` 위치에 `main_lvN.png`를 그린다. 순서는 지도 바닥·덮개 다음, 차보다 먼저다.
2. 꾸미기 색으로 `sign_mask_lvN.png`의 흰 부분을 칠해 건물 위에 겹친다.
3. 간판 문구(`ShopAppearance.sign`)를 네 꼭짓점 사각형에 맞춰 그린다.
   - 간판은 정면(왼쪽 아래 면)과 나란해서, 글자가 오른쪽으로 내려가는 기울기(약 +26.6°)가 된다. 시안 HTML의 `skewY(26.565deg)`와 같다.
   - 글자는 그림처럼 확대하지 말고 화면 해상도로 그린다.
   - 글자색은 간판 색이 어두우면 밝게(시안은 노랑), 밝으면 어둡게 한다.

- Lv1은 `main_lv1`, Lv2 이상은 `main_lv2`를 쓴다. 지금 앱과 같은 구분이다.
- 그림자는 반투명 남색 한 겹이며 그림 파일에 들어 있다.
- 시안의 사람·간판 입간판·나무·꽃나무는 #171(경민) 소품이라 건물 그림에 넣지 않았다.
