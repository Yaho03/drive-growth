# 게임 PV(홍보 영상) 애니메이션 요청 — 웅장한 판타지 트레일러 톤의 렌터카 가게

## 0. 전제

- 같은 캔버스에 애니메이션으로 만든다: https://claude.ai/artifact/TR3ciN6J9HkLX2okkRuhRx
- 그림 스타일은 **확정한 2차 시안 A**를 그대로 쓴다.
  - 쿼터뷰 픽셀, 공용 32색
  - 2차 차량 시트·사람 시트의 차와 사람
- 톤은 **웅장한 다크 판타지 게임 트레일러의 연출 문법**을 빌린다. 어두운 화면, 낮게 울리는 북소리, 불꽃, 느린 카메라, 비장한 자막이다.
  - 그 무게감으로 "작은 렌터카 가게가 커 가는 이야기"를 보여 준다. 진지한 연출과 귀여운 픽셀 가게의 대비가 웃음 포인트다.
- **특정 게임을 따라 만들지 않는다.**
  - 다른 게임의 로고, 제목 글꼴, 캐릭터, 장면 구도, 음악, 대사는 쓰지 않는다.
  - "분위기만 빌린 오리지널 연출"이다.
- 영상 비율은 **16:9, 1920×1080**이고 길이는 **약 40초**다.

## 1. 주인공: 망치를 내려치는 대장장이 사장

- 우리 가게 사장이 **대장간에서 거대한 망치로 무언가를 내려친다.** 불꽃이 튀는 실루엣 장면이 영상의 상징이다.
- 내려치는 대상은 **빛나는 차 열쇠**다. 마지막 타격 때 열쇠가 금빛으로 빛나며 차가 태어난다.
- 캐릭터는 2차 사람 시트의 직원 스타일로 새로 그린 **오리지널 사장**이다.
  - 작업복, 앞치마, 두건 차림이다.
  - 실루엣과 역광으로 크고 웅장하게 보이게 한다.
- 캐릭터 이름·얼굴은 나중에 바꿀 수 있게 단순하게 둔다. 공식 캐릭터(예: 르르르)는 **사용 권리 확인 전까지 넣지 않는다.**

## 2. 장면 구성 (약 40초)

| 시간 | 장면 | 연출 | 자막(예시, 화면 아래 가운데) |
|---|---|---|---|
| 0–4초 | 완전한 어둠 → 멀리 작은 불씨 하나 | 낮은 북소리 자리, 느린 확대 | "아주 오래전, 이 땅에는 차고 세 칸이 있었다." |
| 4–11초 | 대장간. 사장의 실루엣이 망치를 높이 든다 | 역광, 화면이 흔들리며 망치가 내려침. 불꽃 폭발. 3번 내려칠 때마다 컷이 빨라진다 | "그리고 한 사장이 있었으니—" |
| 11–15초 | 마지막 타격, 열쇠가 금빛으로 빛남 → 섬광 | 하얀 섬광으로 장면 전환 | "그는 렌터카를 빚는 자였다." |
| 15–22초 | 쿼터뷰 픽셀 가게 전경. 가게가 **Lv1 → Lv4로 자라는 빠른 타임랩스** | 주차 칸이 3 → 5 → 7 → 10칸으로 열리고, 울타리가 걷히고, 주유소·보험·세차장이 차례로 선다. 2층 본관과 별관이 올라간다 | "가게는 넓어지고," |
| 22–28초 | 뽑기 장면. 어두운 배경에 카드 한 장이 돌다가 **전설 등급 금테**로 열림 | 금빛 반짝임, 느린 회전, 쿼터뷰 차 등장 | "전설은 깨어난다." |
| 28–34초 | 손님들이 차 열쇠를 받고, 차들이 도로를 따라 화면 밖으로 출발. 해 질 녘 | 카메라가 천천히 뒤로 빠짐. 가로등이 켜짐 | "모든 여정은, 이 가게에서 시작된다." |
| 34–38초 | 검은 화면 → 게임 제목 | 제목 글자가 불꽃 속에서 떠오름. 글꼴은 굵은 한글 세리프 계열의 오리지널 스타일 | **[게임 제목]** |
| 38–40초 | 마무리 문구 | 조용히 페이드 | "운전은 안전하게. 게임은 주차 중에." |

## 3. 지킬 것

- 다른 게임·영화의 로고, 제목 글꼴, 캐릭터, 특정 장면, 음악, 대사를 쓰지 않는다. 웅장한 트레일러라는 분위기만 빌린다.
- 실제 자동차 회사 로고·엠블럼·차명 글자를 쓰지 않는다. 차는 2차 시트의 오리지널 픽셀 차다.
- 공식 캐릭터(르르르 등) 이미지는 권리 확인 전까지 넣지 않는다.
- **운전 중 화면 조작 장면을 넣지 않는다.** 게임 화면은 주차한 상태에서만 보여 준다. 마지막 안전 문구는 꼭 넣는다.
- 영상 속 숫자(칸 수 3/5/7/10, 전설 등급 등)는 게임 규칙과 맞춘다. 가격 같은 숫자는 화면에 크게 넣지 않는다.

## 4. 소리

- 애니메이션에는 소리 자리만 표시한다. 북소리, 망치 타격, 섬광, 반짝임, 마지막 정적 구간이다.
- 실제 음악과 효과음은 사용 허가가 분명한 무료 음원으로 따로 넣는다. 다른 게임의 음악은 쓰지 않는다.

## 5. 받고 싶은 결과물

1. 40초 애니메이션 1개(16:9)
2. 장면별 정지 컷 7장(위 표의 장면마다 1장), 썸네일 겸용
3. 망치 내려치는 장면의 **3단 컷**(들어 올림 → 내려침 → 불꽃)
