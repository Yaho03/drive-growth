# 탁송 연출 요청 — 차를 트럭에 싣고 고속도로로

## 0. 전제

- 4차 연출을 만든 Claude Design 프로젝트에 이어서 보드를 추가한다: https://claude.ai/design/p/7bdee427-129e-4c50-ae71-fdd5007563df
  - 보드 제목은 "5차 · 탁송 연출"로 묶는다.
  - 4차 연출(뽑기 셔터·첫 지급·정산 동전·가게 확장)과 **같은 톤, 같은 코드 구조**로 만든다. 시간 t를 받아 그리는 조각이면 우리 HTML 시제품에 바로 옮길 수 있다.
- 스타일은 **확정한 2차 시안 A**를 따른다. 쿼터뷰 픽셀, 공용 32색, 2차 차량 시트, 3차 화면 시안의 어두운 둥근 카드와 파란 버튼이다.
- 화면 크기는 **1360×948**(Pleos 가로)이다.
- **주차 중에만** 보는 연출이다. 운전 중에는 게임 화면을 띄우지 않는다.
- 차 그림 아래에는 **바닥 그림자를 그리지 않는다**(2026-11-12 결정). 트럭도 같다.

### 게임 안에서 탁송이란

- 플레이어가 주차 중에 목적지(예: 마트 4km · 학교 18km · 본가 46km)를 고르고 탁송 의뢰를 하나 고른다.
  - **수익 탁송:** 손님 차를 옮겨 주고 완료 보상을 받는다.
  - **구매 탁송:** 원하는 차를 사서 우리 가게로 데려온다.
- 그다음 플레이어는 **실제로 운전**한다. 게임 속에서는 그동안 트럭이 차를 싣고 목적지로 간다.
- 목적지에 주차하면 도착이 확인되고, 앱을 열었을 때 결과가 나온다.

이 흐름에 맞춰 연출을 세 장면으로 나눈다.

## 1. 트럭 디자인

- **차 한 대를 싣는 오리지널 운반 트럭**이다. 짐칸이 뒤로 미끄러지며 기울어 경사판이 되는 방식이다.
- 생김새:
  - 흰 운전석
  - 짙은 남색 짐칸
  - 운전석 옆면에 굵은 띠 하나. 띠 색은 **우리 가게 간판 색**을 따른다. 앱에서 가게 간판 색으로 바꿔 칠할 수 있게 띠는 따로 그린다.
  - 운전석 지붕에 노란 경광등
  - 짐칸 끝에 차를 고정하는 끈. 구매 탁송이면 끈을 **희귀도 색**(일반 회색 · 고급 파랑 · 희귀 분홍 · 전설 금색)으로 칠한다.
- 크기: 차 기본형(가로 56~73px)보다 1.5배쯤 크게, 원본 약 **110×75px**. 다른 그림과 같은 2:1 쿼터뷰이고, 오른쪽 아래(↘)를 향한다.
- 회사 로고·글자·번호판 문자는 넣지 않는다.
- 실린 차는 우리 차 그림을 그대로 쓴다. 차종이 바뀌어도 짐칸 위 같은 자리에 올라가게 기준점을 맞춘다.

## 2. 장면 흐름

### 2-1. 출발 — 차를 싣고 떠난다 (약 2.5초)

탁송 화면에서 **"의뢰 확정"·"구매 확정"을 누른 직후** 재생한다.

| 단계 | 시간 | 내용 |
|---|---|---|
| ① 트럭 도착 | 0.0–0.6초 | 우리 가게 지도 앞 도로로 트럭이 들어와 주차장 입구 앞에 "끽" 멈춘다. 멈출 때 차체가 앞으로 살짝 쏠렸다 돌아온다 |
| ② 경사판 | 0.6–1.0초 | 짐칸이 뒤로 미끄러지며 기울어 바닥에 닿는다. 닿는 순간 작은 먼지 |
| ③ 싣기 | 1.0–1.6초 | 차가 경사판을 따라 "덜컹" 올라간다. 끝에서 한 번 튕긴다. 수익 탁송은 손님 차가 주차장에서, 구매 탁송은 판매처 쪽 도로에서 들어온다 |
| ④ 고정 | 1.6–1.9초 | 짐칸이 수평으로 돌아오고 고정 끈이 "착" 감긴다. 구매 탁송은 끈이 희귀도 색으로 한 번 반짝인다 |
| ⑤ 출발 | 1.9–2.5초 | 경광등이 천천히 돌고, 트럭이 도로를 따라 ↘ 방향으로 빠져나간다. 화면 위에 "탁송 출발! · 학교 18km" 띠가 나타난다 |

- **건너뛰기** 버튼(오른쪽 위)을 둔다.
- 마지막에 "확인" 버튼 → 진행 중 탁송 화면으로 간다.

### 2-2. 가는 중 — 고속도로를 달리는 트럭 (반복 재생)

**진행 중 탁송 화면**(3차 시안 4x)의 위쪽 큰 그림 자리에 넣는다. 플레이어가 중간에 주차하고 앱을 열었을 때 보는 장면이다.

- 쿼터뷰 고속도로가 화면을 ↘ 방향으로 가로지른다. 트럭은 가운데쯤에 머물고 **배경이 흘러간다.** 4~6초 길이로 **이음매 없이 반복**되어야 한다.
- 흘러가는 것:
  - 차선 점선
  - 가드레일과 방음벽
  - 가로수
  - 초록 고속도로 표지판(목적지 이름과 남은 거리를 쓰는 자리)
  - 멀리 보이는 언덕과 마을 지붕
- 옆 차선에 우리 차 기본형들이 가끔 지나간다. 트럭보다 빠르거나 느리게.
- 트럭은 이음매를 지날 때 1px씩 통통 튄다. 경광등은 천천히 돈다.
- 위쪽 정보 띠: 출발지(우리 가게) → 목적지 진행 막대. 막대 위에 작은 트럭 아이콘이 있다.
  - 진행률은 **실제로 확인된 운전 거리**만 반영한다. 예상 거리로 미리 채우지 않는다.
- 상태별로 정보 띠만 바꾼 정지 컷을 만든다.

| 상태 | 정보 띠 |
|---|---|
| 진행 중 | "학교까지 · 12.4 / 18km" |
| 확인 대기 | 회색 "도착 확인 대기 중 · 다음 주차 때 다시 확인해요". 트럭은 휴게소에 서 있다 |
| 기한 임박 | 노란 "남은 시간 3시간". 재촉하는 문구는 쓰지 않는다 |

### 2-3. 도착 — 내려놓기 (약 1.5초)

도착이 확인된 뒤 **정산 화면을 열 때** 맨 앞에 재생한다.

| 단계 | 시간 | 내용 |
|---|---|---|
| ① 정차 | 0.0–0.4초 | 트럭이 들어와 멈춘다. 구매 탁송은 우리 가게 앞, 수익 탁송은 목적지(작은 건물 앞) |
| ② 내리기 | 0.4–1.1초 | 짐칸이 기울고 차가 미끄러져 내려온다 |
| ③ 이어짐 | 1.1–1.5초 | 구매 탁송: 이미 요청한 **"구매 탁송 도착"** 연출(빈 주차 칸에 "착", 칸 테두리가 희귀도 색으로 빛남)로 이어진다. 수익 탁송: **"수익 탁송 완료"** 도장과 보상 동전으로 이어진다 |

- 차고가 꽉 찬 구매 탁송은 차가 임시 보관함 아이콘으로 들어간다.

## 3. 받고 싶은 결과물

1. **출발 연출** 2종: 수익 탁송, 구매 탁송(희귀도 끈 반짝임 포함)
2. **고속도로 반복 장면** 1종과 정보 띠 상태 정지 컷 3장
3. **도착 연출** 2종: 구매 탁송(가게 앞), 수익 탁송(목적지)
4. **움직임 줄이기 버전**: 흔들림·흐르는 배경 없이 트럭 정지 그림 + 진행 막대만 있는 화면
5. **트럭 스프라이트 시트**(원본 크기, 투명 배경): 짐칸 수평 / 미끄러짐 / 기울어짐 3단계, 경광등 2프레임, 바퀴 2프레임. 가게 간판 색 띠는 따로 떼어 둔다
6. 연출마다 **타이밍 메모 1장**: 단계별 시작 시각, 길이, 효과

## 4. 지킬 것

- 특정 게임·실제 운송 회사의 트럭 디자인·로고·색 조합을 따라 하지 않는다.
- 실제 자동차 회사 로고·엠블럼·차명 글자는 넣지 않는다. 공식 캐릭터(르르르 등)도 넣지 않는다.
- 경광등과 섬광은 빠르게 깜빡이지 않는다. 화면 전체가 0.15초 이상 하얗게 유지되지 않게 한다(광과민성 배려).
- 운전을 재촉하거나 속도를 칭찬하는 문구를 넣지 않는다. 예: "빨리 달려요", "과속 보너스"
- 트럭이 위험하게 달리는 모습(차선 넘나들기, 급정거 연속)은 그리지 않는다.
- 표지판·정보 띠 글자는 앱이 얹는 자리로 비워 두거나 따로 떼어 그린다.
- 소리는 자리만 표시한다(끽, 덜컹, 착, 엔진 소리).

## 5. 판정 기준

- 탁송을 고르면 "내 차가 실려 간다"는 게 한눈에 보이는가?
- 고속도로 장면을 오래 켜 둬도 이음매가 튀지 않고 거슬리지 않는가?
- 진행 막대가 실제 운전 거리만 보여 주는지, 상태(진행 중·확인 대기·기한 임박)를 바로 알 수 있는가?
- 2차 시안 A의 픽셀 가게, 4차 연출과 같은 게임으로 보이는가?
