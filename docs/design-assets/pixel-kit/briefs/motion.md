# 게임 연출 애니메이션 요청 — 뽑기(가챠) 연출 + 게임 순간별 짧은 연출

## 0. 전제

- 같은 캔버스에 애니메이션 보드로 추가한다: https://claude.ai/artifact/TR3ciN6J9HkLX2okkRuhRx
  - 보드 제목은 "4차 · 연출"로 묶는다.
- 스타일은 **확정한 2차 시안 A**를 따른다. 쿼터뷰 픽셀, 공용 32색, 2차 차량·사람 시트, 3차 화면 시안의 어두운 둥근 카드와 파란 버튼이다.
- 화면 크기는 **1360×948**(Pleos 가로)이다.
- 차량 화면에서 **주차 중에만** 보는 연출이다. 운전 중에는 재생하지 않는다.
- **목표:** 요즘 모바일 게임 뽑기처럼 **화려하고 두근거리게** 만든다. 다만 특정 게임의 연출·캐릭터·이펙트를 그대로 따라 하지 않고, 우리 게임 소재(**차고 셔터, 차 열쇠, 주차 칸, 렌터카**)로 만든 오리지널 연출이어야 한다.
- 숫자와 규칙은 PRD 시험값이다.
  - 뽑기 500, 확률 일반 74.7% · 고급 20% · 희귀 5% · 전설 0.3%, 30회 안에 희귀 이상 보장
  - 주차 칸 3/5/7/10, 초기 재화 1,000

## 1. 뽑기 연출 (가장 중요)

**콘셉트: "셔터가 올라가면 새 차가 있다".** 빛이 새어 나오는 차고 셔터가 내려오고, 셔터 틈의 빛 색깔로 등급을 미리 알려 준다. 탭하면 셔터가 올라가며 차가 공개된다.

### 장면 흐름

| 단계 | 시간 | 내용 |
|---|---|---|
| ① 등장 | 0.0–0.5초 | 화면이 어두운 남색으로 덮인다. 위에서 픽셀 차고 셔터가 "쿵" 떨어진다. 착지 순간 바닥 먼지가 튀고 화면이 살짝 흔들린다 |
| ② 예고 | 0.5–2.0초 | 셔터 아래 틈으로 **빛이 새어 나온다.** 빛 색이 등급을 알려 준다(아래 표). 바닥의 주차 칸 마름모 선이 빛나며 고리가 퍼지고, 작은 불씨가 위로 떠오른다 |
| ③ 승급 연출 | 희귀·전설만 | 빛이 한 단계 낮은 색으로 시작했다가 **"번쩍" 하며 윗등급 색으로 바뀐다.** 전설은 파랑 → 분홍 → 금색으로 두 번 바뀌고, 바뀔 때마다 흔들림과 섬광이 커진다. 요즘 뽑기의 "승급" 두근거림을 주는 핵심 장면이다 |
| ④ 대기 | 2.0초 이후 | "화면을 눌러 셔터 올리기" 문구가 숨 쉬듯 깜빡인다. 3초 동안 누르지 않으면 자동으로 다음 단계로 간다 |
| ⑤ 개봉 | 0.55초 | 셔터 판이 아래에서 위로 말려 올라가며 안쪽 빛이 쏟아진다. 다 올라가는 순간 하얀 섬광 |
| ⑥ 공개 | 0.5초 + 유지 | 등급 색의 **빛줄기**가 차 뒤에서 천천히 돈다. 차가 작게 시작해 살짝 튕기며 커진다(오버슛). 반짝이 입자가 고리 모양으로 터지고, 차는 바닥 희귀도 테두리 위에서 천천히 위아래로 떠 있다 |
| ⑦ 결과 카드 | 0.9초부터 | 등급 띠("★ 전설 등급! ★"), 차 이름, 희귀도 칩, Lv1, **처음 얻은 칸이면 "NEW · 도감 등록"** 표시. 버튼은 "한 번 더 뽑기"와 "차고에서 보기" |

### 등급별 차이 (모두 그린다)

| 등급 | 셔터 틈 빛 | 공개 효과 | 결과 |
|---|---|---|---|
| 일반 | 흰빛, 잔잔함 | 작은 반짝임 | 차분한 카드 |
| 고급 | 파란빛 | 파란 빛줄기, 반짝임 고리 | 파란 테두리 카드 |
| 희귀 | 파랑 → **분홍으로 승급** | 분홍 빛줄기, 큰 반짝임, 짧은 흔들림 | 이중 테 카드 |
| 전설 | 파랑 → 분홍 → **금색으로 2단 승급**, 승급 때마다 섬광 | 금색 빛줄기 2겹, 화면 흔들림, **색종이와 금빛 별이 계속 떨어짐**, 차 뒤 후광, 2번째 폭발 | 금테·빛나는 카드, "★ 전설 등급! ★" |

### 뽑기에 꼭 넣을 것

- **건너뛰기** 버튼(오른쪽 위)을 둔다. 바로 결과 카드로 간다.
- **천장 연출:** 30회째 보장으로 나온 희귀 이상은 결과 카드에 "보장 달성!" 작은 배지를 단다. 다음 보장은 30회부터 다시 센다.
- **움직임 줄이기 설정:** 흔들림·섬광·빛줄기 없이 셔터가 열리고 결과 카드가 나타나는 간단한 버전 1장을 만든다(접근성).
- 반짝임·색종이·불씨는 **픽셀 입자**(작은 네모·십자 별)로 만든다. 부드러운 블러 입자는 쓰지 않는다.

## 2. 짧은 연출 3종

### 2-1. 첫 지급 (첫 실행 마지막 화면)

1. 카드 3장(초기 게임머니 1,000 · 첫 차 · 차고 3칸)이 0.15초 간격으로 아래에서 튀어 오른다.
2. 게임머니 카드에서 동전이 분수처럼 튀고, 숫자가 0에서 1,000까지 굴러 올라간다.
3. 첫 차 카드에서는 차 열쇠가 반짝이며 차가 한 번 경적을 울리듯 통통 튄다.
4. 마지막에 작은 색종이가 날리고 "가게로 가기" 버튼이 나타난다.

전체 약 1.8초.

### 2-2. 정산 동전 (정산 화면 "확인"을 누를 때)

1. 각 줄(기본 주행 수익 · 탁송 결과 · 영업 결과)에서 픽셀 동전이 줄마다 0.12초 간격으로 튀어나온다. 동전은 회전하며 곡선을 그리고 오른쪽 위 보유 게임머니로 날아간다.
2. 동전이 닿을 때마다 게임머니 칸이 살짝 커졌다 작아지며 숫자가 올라간다. 예: 3,240 → 4,190
3. 마지막 동전이 닿으면 합계 숫자에 반짝임이 한 번 지나간다.

전체 약 1.5초. 금액이 클수록 동전 수가 많아지되 최대 12개다.

### 2-3. 가게 확장 (가게 화면 "확장하기"를 누를 때)

1. 화면이 가게 지도로 살짝 확대된다.
2. 새로 열리는 주차 칸의 울타리 판자가 "탁탁" 튕겨 날아가고 흙먼지가 피어오른다. 판자는 중력을 받아 떨어지며 사라진다.
3. 먼지가 걷히면 새 주차 칸의 흰 선이 **한 칸씩 차례로** 빛난다. 예: Lv2 → Lv3이면 2칸
4. 본관이 Lv1에서 Lv2(2층·차고 별관)로 바뀔 때는 건물이 살짝 눌렸다가 "뿅" 커지며 반짝인다.
5. 가운데에 "가게 Lv3!" 띠와 "주차 5 → 7칸"이 나오고 "확인" 버튼이 나타난다.

전체 약 2초. 지도는 2차 시안 A의 지도를 쓴다.

## 2-4. 나머지 게임 순간의 짧은 연출

게임에서 보상·변화가 생기는 다른 순간도 같은 톤으로 만든다. 길이는 대부분 0.6~1.2초로 짧게 하고, 반복해서 봐도 거슬리지 않게 한다.

| 순간 | 연출 | 길이 |
|---|---|---|
| **레벨업** (차량 상세) | 차가 한 번 튀어 오르고, 발밑에서 위로 솟는 빛기둥과 "Lv5 → Lv6" 숫자 굴림. 진행 막대가 채워지며 반짝 | 약 0.9초 |
| **재료 강화** (재료 차 소비) | 재료 차가 빛 입자로 흩어져 대상 차로 빨려 들어가고, 진행 막대가 차오르며 넘치면 레벨업 연출로 이어짐. 진행량(+100% 등)이 떠오름 | 약 1.4초 |
| **수리 완료** | 렌치 아이콘이 두 번 "탕탕" 두드리고, 차에서 연기가 걷히며 상태 칩이 "수리 필요 → 대기"로 바뀌는 반짝임 | 약 0.8초 |
| **판매** | 차가 오른쪽으로 미끄러져 나가며 사라지고, 그 자리에서 동전이 게임머니로 날아감. 도감 "보유 기록은 남아요" 작은 안내 | 약 1.0초 |
| **폐차** | 차가 눌리듯 납작해지며 픽셀 조각으로 부서지고, 적은 동전이 날아감. 너무 슬프지 않게 가볍게 | 약 1.0초 |
| **구매 탁송 도착** (정산) | 도로에서 새 차가 들어와 빈 주차 칸에 "착" 멈추고, 칸 테두리가 희귀도 색으로 빛남. 차고가 꽉 찼으면 임시 보관함 아이콘으로 들어감 | 약 1.3초 |
| **수익 탁송 완료** (정산) | 도장 "완료"가 찍히고 보상 동전이 날아감 | 약 0.8초 |
| **개업 선물** (첫 영업 후) | 리본 달린 선물 상자가 흔들리다 열리며 무료 뽑기권이 튀어나와 빙글 돎. "지금 뽑으러 가기" 버튼 | 약 1.5초 |
| **도감 NEW 등록** | 도감 칸이 실루엣 → 선명한 그림으로 뒤집히며(카드 뒤집기) "NEW" 도장 | 약 0.7초 |
| **시설 설치** (주유소·보험·세차장) | 빈 터에 공사 콘·먼지가 잠깐 생겼다가 건물이 아래에서 "뿅" 솟고 직원이 나타남. 시설 표지가 "운영 중"으로 바뀜 | 약 1.6초 |
| **지도 위 대여 출발·반납** (가게 화면, 반복 재생) | 손님이 차로 걸어가 타면 차가 도로로 빠져나감 / 반납 때 도로에서 들어와 칸에 멈추고 손님이 내림. 은은하게, 작게 | 출발·반납 각 약 2초 |
| **사고 발생** (정산에서 알림) | 차 위에 작은 "!" 말풍선과 연기 한 줄기. 겁주지 않게 가볍게 | 약 0.7초 |

## 3. 받고 싶은 결과물

1. **뽑기 연출 4종**: 일반, 고급, 희귀(1단 승급), 전설(2단 승급). 각각 처음부터 결과 카드까지 재생되는 애니메이션
2. **뽑기 · 움직임 줄이기 버전** 1종
3. **첫 지급, 정산 동전, 가게 확장** 애니메이션 각 1종
4. **2-4절의 나머지 연출 12종**. 짧은 연출이므로 한 보드에 여러 개를 나란히 두어도 된다
5. 뽑기·첫 지급·정산·확장 연출의 **핵심 정지 컷 3장**: 예고 / 승급·폭발 / 결과
6. 각 연출 보드 옆에 **타이밍 메모 1장**: 단계별 시작 시각, 길이, 효과. 앱(Android)으로 옮길 때 그대로 쓴다

## 4. 지킬 것

- 특정 게임의 뽑기 연출, 캐릭터, 효과음, 이펙트 모양을 그대로 따라 하지 않는다. 소재는 차고 셔터·열쇠·주차 칸·차로 만든다.
- 실제 자동차 회사 로고·엠블럼·차명 글자는 넣지 않는다. 공식 캐릭터(르르르 등)도 넣지 않는다.
- 섬광은 화면 전체가 **0.15초 이상 하얗게 유지되지 않게** 한다. 빠른 깜빡임을 연속으로 쓰지 않는다(광과민성 배려).
- 운전을 재촉하는 문구는 넣지 않는다. 예: "더 달려서 뽑으세요"
- 소리는 자리만 표시한다(셔터 쿵, 승급 차임, 개봉 휘익, 전설 팡파르). 실제 음원은 사용 허가가 분명한 것으로 따로 넣는다.

## 5. 판정 기준

- 전설이 나올 때 "와!" 소리가 나올 만큼 화려한가? 일반도 지루하지 않은가?
- 셔터 틈 빛 색만 보고 등급을 예상할 수 있고, 승급 순간이 두근거리는가?
- 2차 시안 A의 픽셀 가게와 같은 게임으로 보이는가?
- 건너뛰기와 움직임 줄이기 버전으로 반복 뽑기가 답답하지 않은가?
