# 렌터카 가게 메인 화면 — 시안 A 2차 수정 요청

## 0. 이번 요청의 전제

- 1차 시안 중 **시안 A(쿼터뷰 픽셀)로 방향을 확정**했다. 시안 B는 더 만들지 않는다.
- 같은 캔버스에서 A를 수정한다. 기존 4장은 비교용으로 남긴다. 캔버스: https://claude.ai/artifact/TR3ciN6J9HkLX2okkRuhRx
- 유지할 것: 땅 위 구도, 화면 밖으로 이어지는 땅·숲·도로, 잠긴 시설 터와 확장 구역의 표현, 왼쪽 위·오른쪽 위 상태 카드, 지도 위 시설 표지, 확장 전후 비교.

## 1. 가장 중요한 수정: 차를 주인공으로

이 게임의 핵심은 **차를 모으고 키우는 재미**다. 1차의 차는 상자 두 개를 쌓은 모양이어서 차종이 색으로만 구별된다. 2차에서는 차가 지도에서 가장 눈에 띄고 갖고 싶어 보여야 한다.

- **크기:** 원본 기준 가로 약 48px → **약 64px**로 키운다. 사람은 그에 맞춰 약 32px로 한다.
- **모양:** 각진 상자 대신 **둥글고 귀여운 실루엣**으로 한다. 첨부한 원래 로우폴리 시안의 차처럼 통통한 비율이다.
- **세부:** 바퀴(휠 하이라이트 포함), 앞 유리와 옆 유리, 헤드라이트·테일라이트, 범퍼를 1~2px로 또렷하게 그린다.
- **차종별 실루엣:** 색을 빼고 흑백으로 봐도 구별되어야 한다.

| 기본형 | 실루엣 특징 |
|---|---|
| 경차 | 짧고 높다. 둥근 박스형에 큰 창문 |
| 세단 | 길고 낮다. 트렁크가 튀어나옴 |
| SUV | 높고 각지다. 루프랙, 큰 바퀴 |
| 승합 | 가장 길고 높다. 옆 창이 여러 칸 |
| 고급 세단 | 가장 길다. 크롬 라인과 짙은 색 |

- **희귀도 미리보기:** 주차장 차 중 1대는 희귀 등급 예시로 그린다. 차 그림은 그대로 두고, 차 아래 바닥에 은은한 색 테두리나 빛 원을 둔다.
- **로고 없음:** 실제 브랜드 로고·엠블럼·번호판 문자는 넣지 않는다.

## 2. 글자는 그림에서 빼기

- 1차에서는 간판·표지판 글자("렌터카", "공사 예정", "확장 예정")가 픽셀 그림 안에 그려져 깨져 보였다.
- 2차에서는 **그림 안에 글자를 넣지 않는다.** 간판·표지판은 빈 판으로 그린다.
- 그 위에 **HTML 텍스트로 얹는다.** 실제 앱도 글자를 따로 얹는다.
- 간판 텍스트는 가게 이름 자리로 임시 "렌터카"를 쓴다. 굵은 한글 폰트를 쓰고, 지도 위에서도 읽히도록 어두운 테두리나 판을 둔다.

## 3. 더 붐비는 가게

"렌터카·시설·일하는 사람이 많은" 느낌이 나야 한다. 다만 지도가 지저분해지지 않도록 길과 빈 땅을 남긴다.

- **건물·시설:** 본관과 주유소 외에 **정비소(차 1대 리프트에 올라감)**를 운영 중으로 추가한다. 잠긴 보험·세차장 터는 유지한다.
- **사람:** 6~8명이 각자 다른 일을 한다.
  - 주유하는 직원
  - 정비소 정비사(차 아래)
  - 본관 앞 안내 직원
  - 차 열쇠 받는 손님
  - 차로 걸어가는 손님 2명
  - 세차 터를 보는 직원
- **움직임 암시:** 걷는 자세와 서 있는 자세를 섞는다. 한 사람은 차 문을 열고 있다.
- **차:** 주차장 8칸 중 6대, 도로에서 들어오는 차 1대, 나가는 차 1대를 둔다.
- **소품 다양화:** 나무 3종 이상(침엽수, 둥근 나무, 꽃나무)을 쓴다. 같은 나무가 줄지어 반복되지 않게 한다. 화단, 벤치, 자판기, 안내 입간판, 콘을 둔다.

## 4. 3D처럼 보이게 다듬기

- 차·사람·건물 아래 **바닥 그림자**를 1차보다 조금 더 진하게 한다. 빛은 왼쪽 위에서 오고, 그림자는 오른쪽 아래로 떨어진다.
- 건물과 차의 윗면·왼면·오른면 명암을 3단계로 또렷이 구분한다.
- 가로등 아래와 본관 창문에 은은한 빛 번짐을 넣는다(낮이라 약하게).
- 픽셀 규칙은 1차와 같다.
  - 정수 배율 확대, 흐림 없음
  - 32색 이내 한 팔레트
  - 1px 어두운 외곽선

## 5. 받고 싶은 결과물

1. **A 메인 화면 2차** 1장. 1440×960이며 1차와 같은 화면 비율·HUD다.
2. **A 확장 후 2차** 1장. 주차장 16칸, 정비소 유지, 보험 시설 열림(운영 중)이다.
3. **차량 시트** 1장:
   - 기본형 5종 × ↘ 방향 1장씩
   - 그중 1종(경차)은 4방향 ↘ ↙ ↗ ↖
   - 희귀도 4단계 바닥 표시 예시: 일반·고급·희귀·전설. 색만이 아니라 모양이나 밝기도 다르게 한다.
4. **사람 시트** 1장:
   - 직원·정비사·손님 2종
   - 각각 서 있기 1프레임 + 걷기 2프레임
   - 걷기 2프레임은 다리 위치가 분명히 달라야 한다.

## 6. 꼭 지킬 것

- 차량 화면이므로 HUD 글자와 버튼은 크고 또렷하게 한다. 터치 영역은 44px 이상이다.
- 운전을 재촉하는 표현(카운트다운, 깜빡이는 알림)은 넣지 않는다.
- 숫자(6/8, 16칸, 손님 100명, 레벨 3)는 예시이며 최종 값이 아니다.
- 실제 자동차 회사·캐릭터 브랜드의 이미지·로고는 쓰지 않는다.
