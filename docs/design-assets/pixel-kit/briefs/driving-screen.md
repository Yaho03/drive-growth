# 주행 중 화면 연출 요청 — 르르르가 트럭을 운전하는 정면 뷰

## 0. 전제

- 지금까지 연출을 만든 Claude Design 프로젝트에 이어서 보드를 추가한다: https://claude.ai/design/p/7bdee427-129e-4c50-ae71-fdd5007563df
  - 보드 제목은 "9차 · 주행 중 화면"으로 묶는다.
- **같이 올리는 파일**
  - 최신 게임 시제품 `prototype.html`
  - 르르르 걷기·대기 프레임(`walk1~8.png`, `idle3~5.png`)과 7차 휴게소 연출의 르르르(운전석 장면)
  - 탁송 트럭 그림 `truck.png`, 고속도로 배경 `highway.png`
  - 8차 시작화면 보드(포스터 톤 참고)
- 4차~8차와 **같은 코드 구조**로 만든다. 시간 t를 받아 화면을 그리는 조각이고, 글자는 값으로 받는다.
- 화면 크기는 **1360×948**(Pleos 가로)이다. 좁은 창(840×1184)도 한 장 받는다.

### 이 화면이 하는 일 — 가장 중요

- 운전을 시작하면 게임 화면은 잠기고 이 화면 하나만 남는다. **조작할 것이 없고, 읽을 정보도 거의 없는 화면**이다.
- 우리 기획의 최우선 원칙은 **"주행 중에는 화면을 보게 하지 않는다"**이다. 그래서 이 화면의 목표는 "보고 싶게 만드는 것"이 아니라 **"흘끗 봐도 '지금은 운전 중이라 쉬는 화면이구나' 하고 바로 눈을 돌리게 하는 것"**이다.
- 느낌: 르르르도 같이 운전 중이니 사장님도 운전에 집중하세요. 차분하고 포근하게.
- 실제 차량 앱에 넣을지는 팀이 Pleos 주행 중 화면 정책(#80·#81)과 함께 확인한 뒤 정한다. 허용되지 않으면 **시연 영상과 주차 후 "주행 기록 다시 보기"** 용도로만 쓴다.

## 1. 장면 — 앞유리 너머로 본 운전석

- **정면 뷰:** 도로 쪽에서 트럭 앞유리를 바라본 구도다. 운전석에 르르르가 앉아 두 손으로 운전대를 잡고 앞을 보고 있다.
- 우리 탁송 트럭(흰 운전석, 옆 띠, 지붕 경광등)의 앞모습이다. 앞유리 틀, 사이드미러, 와이퍼, 대시보드 위 작은 차 장식이 보인다.
- 앞유리에는 하늘·도로·나무가 옅게 비친다. 비친 풍경이 아주 천천히 위로 흘러가서 "달리는 중"을 보여 준다.
- 배경 시간대는 낮 기본, 밤 버전 하나. 밤에는 계기판 청록 불빛이 르르르 얼굴을 살짝 비춘다.
- 그림체는 우리 게임 그대로 **픽셀**이다. 블러 대신 디더링과 단계 색을 쓴다.

## 2. 움직임 — 아주 조용하게

반복 10~12초, 이음매 없이. **한 번에 하나만**, 모두 느리게 움직인다.

| 움직임 | 주기 | 내용 |
|---|---|---|
| 차체 흔들림 | 상시 | 1~2픽셀, 아주 느린 위아래 |
| 비친 풍경 | 상시 | 앞유리 반사가 천천히 흐름 |
| 르르르 깜빡임 | 4~5초에 한 번 | 눈 깜빡 |
| 귀 흔들림 | 반복마다 한 번 | 르르르 귀가 바람에 살짝 흔들림 |
| 차 장식 | 반복마다 한 번 | 대시보드 장식이 살짝 흔들림 |

- **넣지 않는 것:** 빠른 움직임, 깜빡임, 번쩍임, 입자 폭발, 숫자·거리·속도 표시, 보상·동전, 손 흔들기처럼 시선을 끄는 동작, 운전대를 크게 돌리는 동작.
- 전체 밝기는 차량 화면에서 눈부시지 않게 **어둡고 대비 낮게** 한다(밤 운전 고려).

## 3. 글자

- 화면 아래에 한 줄만 둔다: **"운전 중에는 화면을 쉬어요"** (값으로 받음).
- 작은 회색 글씨, 화면의 10% 안. 버튼은 없다.
- "더 달리면 ○○", "N km 남았어요"처럼 **운전을 재촉하거나 거리를 보여 주는 문구는 절대 넣지 않는다.**

## 4. 르르르 — 꼭 지킬 것

- **보내 준 르르르 프레임 생김새를 그대로** 따른다. 정면 운전 자세에 필요한 부분(운전대를 잡은 손, 앞을 보는 얼굴)만 같은 그림체로 더한다.
- **르르르는 별도 층**으로 그린다.
- **대체 버전도 함께:** 르르르 대신 정비사가 운전하는 버전. 르르르 출품 사용권(#29) 확인 결과에 따라 바꿔 쓴다.

## 5. 받고 싶은 결과물

1. 반복 애니메이션: 낮·밤 × 르르르·정비사 (4가지)
2. **움직임 줄이기 버전:** 완전한 정지 그림 한 장(깜빡임만 허용 여부 표시)
3. 좁은 창(840×1184) 배치 한 장
4. 타이밍 메모와 더한 색 목록
5. 시제품에 옮길 수 있는 코드(시간 t → 화면, 글자·시간대·주인공은 props)

## 6. 소리

- 효과음·음악을 넣지 않는다. 주행 중에는 소리로 주의를 끌지 않는다. (소리 자리 표시 없음)

## 7. 지킬 것

- 실제 자동차 회사 로고·엠블럼·차명, 실제 도로 표지·상표를 넣지 않는다.
- 섬광·빠른 깜빡임 금지(광과민성). 밝은 흰 면적을 크게 두지 않는다.
- 운전을 재촉하거나 속도·거리를 칭찬하는 표현 금지.
- 사고, 졸음, 휴대폰을 보는 모습 등 위험 운전을 떠올리게 하는 장면 금지. 르르르는 항상 두 손으로 운전대를 잡고 앞을 본다.

## 8. 판정 기준

- 1초 흘끗 봤을 때 "운전 중 쉬는 화면"으로 읽히고, 더 볼 이유가 없는가?
- 10분 켜 두어도 눈에 거슬리지 않는가?
- 트럭과 르르르가 탁송·휴게소 연출과 같은 게임으로 보이는가?
