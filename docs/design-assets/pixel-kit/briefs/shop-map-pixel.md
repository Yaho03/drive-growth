# 렌터카 가게 메인 화면 — 쿼터뷰 픽셀 시험 시안 요청

## 1. 무엇을 만드는가

차량 화면(Pleos Connect)에서 **주차 중에** 보는 방치형 렌터카 가게 게임의 메인 화면이다. 플레이어는 렌터카 가게 사장이다. 차를 모아 주차장에 두면 손님이 빌려 가고, 가게와 시설이 점점 커진다.

이번 요청은 **그림 방식을 시험하는 시안**이다. 최종 디자인이 아니다. 같은 구성을 두 가지 방식으로 그려 비교하려고 한다.

## 2. 지금 화면과 바꾸고 싶은 점

첨부한 현재 시안을 보면, 하늘색 배경 위에 **떠 있는 섬**이 있고 그 위에 로우폴리 3D 가게가 올라가 있다.

- 섬 가장자리와 흙 단면이 보여서 **하늘에 떠 있는 느낌**이 든다.
- 땅이 좁아서 앞으로 렌터카·시설·직원이 늘어날 공간이 느껴지지 않는다.
- 잠긴 시설이 오른쪽 아래에 글자 목록으로만 있다.

**목표 느낌:** 클래시 오브 클랜처럼 **땅 위에서 내려다보는** 느낌이다. 땅이 화면 밖까지 이어지고, 차와 사람이 많이 움직이며, 넓어질 땅이 보여야 한다.

## 3. 그림 방식

### 시안 A (주안): 쿼터뷰 픽셀 아트 — "3D처럼 보이는 2D 픽셀"
- 2:1 아이소메트릭 쿼터뷰로, 지금 시안과 비슷한 각도로 비스듬히 내려다본다.
- 3D 로우폴리 모델을 저해상도로 렌더한 듯한 픽셀 느낌이다. 면의 명암이 3단계 정도로 또렷하다.
- 3D 느낌을 내는 장치:
  - 모든 차·사람·건물 아래에 **바닥 그림자**를 둔다.
  - **앞뒤 가림**을 지킨다. 사람이 차 뒤로 지나가면 차에 가려진다.
  - 은은한 **빛 방향**을 정한다. 빛은 왼쪽 위에서 오고, 그림자는 오른쪽 아래로 떨어진다.
  - 지도 가장자리는 살짝 어둡고 흐리게 해서 깊이감을 준다.
- 픽셀 규칙:
  - 픽셀은 정수 배율로만 확대한다(3배 또는 4배). 흐린 확대는 쓰지 않는다.
  - 색은 32색 이내의 한 팔레트로 쓴다.
  - 외곽선은 1px 어두운 색이다.
- 크기 기준:
  - 승용차는 원본 기준 가로 약 48px이다.
  - 사람은 높이 약 24~32px이다. 차 옆에 섰을 때 자연스러운 비율이어야 한다.

### 시안 B (비교용): 지금 같은 3D 로우폴리
- A와 **같은 배치·같은 요소**를 지금 시안의 로우폴리 스타일로 그린다.
- 다른 점은 하늘 섬이 아니라 **땅 위**라는 것뿐이다.

## 4. 화면 구성 (A, B 공통)

화면은 가로형 앱 창이며 비율은 약 3:2다. 지도는 화면보다 크고 손가락으로 끌어 둘러보는 것을 전제로 한다. 시안에는 가운데 부분만 보이면 된다.

| 요소 | 내용 |
|---|---|
| 땅 | **화면 전체를 땅으로** 채운다. 하늘·떠 있는 섬·흙 단면은 넣지 않는다. 화면 가장자리 바깥으로 풀밭·나무·울타리가 이어진다. |
| 가게 본관 | 지도 중심 근처에 둔다. 간판 문구는 임시로 "렌터카"를 쓴다. 실제 회사명·로고는 넣지 않는다. |
| 주차장 | 8칸 중 6칸에 차가 있다. 경차·세단·SUV·승합·고급 세단처럼 모양과 색이 다른 차를 섞는다. **실제 브랜드 로고와 엠블럼은 넣지 않고 실루엣만** 쓴다. |
| 도로 | 가게 앞에서 **화면 밖으로 나가는 도로**가 있다. 렌터카 1대가 손님을 태우고 나가는 중이다. |
| 주유소 | 운영 중이고, 직원 1명이 일하고 있다. |
| 보험 시설 | 잠긴 상태다. 빈 터에 자물쇠 표지판을 둔다(조건: 누적 손님 100명). |
| 세차장 | 잠긴 상태다. 빈 터에 공사 예정 표지판을 둔다(조건: 가게 레벨 3). |
| 확장 구역 | 아직 못 쓰는 땅이다. 울타리·풀숲·"확장 예정" 표지판으로 표시하며, 넓어질 공간이 보이게 한다. |
| 사람 | 직원 2명(본관 앞, 주유소), 정비사 1명, 손님 2명(차 받으러 걸어오는 중). 걷는 자세를 섞는다. |
| 소품 | 나무, 가로등, 화단, 벤치를 둔다. 너무 빽빽하지 않게 한다. |

### 화면 위 상태 표시 (HUD)
- 지금 시안처럼 **어두운 둥근 카드**가 지도 위에 떠 있다.
  - 왼쪽 위: "● 정상 영업 중 · 처음 30분"
  - 오른쪽 위: "P 6 / 8"
- 시설 상태는 오른쪽 아래 목록 대신 **지도 위 각 시설 옆의 작은 표지**로 보여 준다. 누르면 조건 안내 말풍선이 나온다고 가정하고, 말풍선 1개를 예시로 그린다.
- 주요 버튼 색은 기존처럼 파란색이다.

## 5. 꼭 지킬 것
- 차량 화면이므로 글자와 버튼은 **크고 또렷하게** 한다. 좁은 창에서도 HUD가 지도에 묻히지 않아야 한다.
- 운전을 재촉하는 표현(카운트다운, 깜빡이는 알림)은 넣지 않는다.
- 숫자(6/8, 100명, 레벨 3)는 예시이며 최종 값이 아니다.
- 실제 자동차 회사·캐릭터 브랜드의 이미지와 로고는 쓰지 않는다.

## 6. 받고 싶은 결과물
1. **시안 A** (쿼터뷰 픽셀) 메인 화면 1장
2. **시안 B** (로우폴리, 땅 위) 메인 화면 1장, A와 같은 배치
3. (가능하면) A의 **요소 시트**
   - 차 1대를 4방향(↘ ↙ ↗ ↖)으로 그린 것
   - 직원 1명의 걷기 2프레임
   - 잠긴 시설 터 1개
4. (가능하면) A의 **확장 후** 모습: 확장 구역이 열려 주차장이 넓어진 상태 1장

## 7. 비교할 기준
- 땅에 붙어 있는 느낌인가? 떠 있는 느낌이 사라졌는가?
- 차종과 사람이 작은 크기에서도 구별되는가?
- 앞으로 차·시설·직원이 늘어날 공간이 느껴지는가?
- 차량 화면 크기에서 HUD 글자가 잘 읽히는가?
- 픽셀(A)과 로우폴리(B) 중 어느 쪽이 "수집하고 키우는 재미"가 더 잘 보이는가?
