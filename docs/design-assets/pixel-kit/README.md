## 공용 팔레트와 크기

2차 시안 A가 실제로 쓴 32색을 그대로 공용 팔레트로 정했다.

| 파일 | 내용 |
|---|---|
| `palette.png` | 32색 원본 (32×1px) |
| `palette.gpl` | Aseprite·GIMP·Pixelorama 팔레트 |
| `palette.hex` | 색 코드 목록 |
| `palette-swatches.png` | 색 견본 (묶음·용도) |
| `size-sample.png`, `size-sample@4x.png` | 차 기본형 5종 + 직원 원본 크기 비교, 32×16 바닥 타일 격자 |
| `ref-sprites/` | 2차 시안에서 잘라낸 기본형 참고 그림(원본 크기, 투명 배경). 참고용이며 최종 그림이 아니다. 차 그림에는 시안의 진초록 바닥 그림자가 남아 있다. 현재 시제품은 아래에 적은 별도 마을 자산을 사용한다 |

크기는 원본 기준이며 2차 시안의 바닥 그림자까지 잰 값이다. 차는 이제 그림자를 그리지 않는다([asset-spec.md](asset-spec.md) 공통 규칙).

| 대상 | 크기(px) |
|---|---|
| 바닥 타일 | 32×16 |
| 경차 | 56×51 |
| 세단 | 66×46 |
| SUV | 69×58 |
| 승합 | 73×64 |
| 고급 세단 | 73×48 |
| 사람(서 있기) | 16×38 |

지도 원본은 640×464이며, 앱은 2배로 확대한다.

## 시제품 (`prototype/`)

`build.py`가 `template.html`에 그림(data URI)과 크기를 넣어 `prototype.html`을 만든다. 2026-11-13부터 그림은 이 키트가 아니라 **경민의 마을 시안 [`../town-preview/assets/`](../town-preview/assets/)**(#229)에서 가져온다: 마을 한 장, 차 20종(차종마다 전용 그림, 색 변환 없음), 손님·정비사·주유소 직원, 르르르 걷기·대기. 안내 직원 자리는 정비사 그림을 쓴다. 위 `map/`·`building/`·`ref-sprites/`는 마을 한 장을 층별 키트로 나눌 때까지 참고용으로만 남긴다(#229 댓글로 원본 요청). 브라우저로 열면 다음을 눌러 볼 수 있다.

- 시작화면: 열 때마다 지도·본관·주차 차량 위에 「르르르 렌터카」 로고가 뜨고, 누르면 가게로 들어간다. 「시험 도구」의 「시작화면」으로 다시 볼 수 있다.
- 화면: 첫 실행, 가게, 차고, 차량 상세, 도감, 뽑기, 탁송, 정산, 랭킹
- 가게 화면의 「시험 도구」: 영업 1시간, 30km 주행, 탁송 도착, 다음 날
- 연출: 뽑기 셔터(등급별), 첫 지급, 정산 동전, 가게 확장. 4차 Claude Design 연출([briefs/motion.md](briefs/motion.md) 요청서)을 `motion.jsx`로 옮겼고, 「연출 다시 보기」 버튼으로 다시 볼 수 있다.
- 탁송 연출: 의뢰를 받으면 트럭이 가게 앞에 서서 차를 싣고 떠나고(출발), 진행 중 탁송 화면 위에 고속도로를 달리는 트럭이 반복 재생되며(확인 대기·진행 중·기한 임박 상태), 도착하면 차를 내려 빈 칸에 놓거나(구매) 목적지에서 도장·보상 동전이 나온다(수익). 5차 Claude Design 연출([briefs/delivery-truck.md](briefs/delivery-truck.md) 요청서)을 `delivery.jsx`로 옮겼다. 목적지 마을 그림(`prototype/dest-town.png`)은 Claude Design의 임시 그림이다.
- 소리: 효과음은 파일 없이 브라우저 WebAudio로 즉석에서 만든다(버튼·동전·셔터·등급 공개·레벨업·탁송 출발). 연출의 「SFX 자리」 글귀를 그대로 소리로 바꾼다. 브금은 `prototype.html` 옆 `bgm/` 폴더의 `title.mp3`·`shop.mp3`·`gacha.mp3`·`delivery.mp3`·`settle.mp3`를 화면에 맞춰 틀고, 파일이 없으면 조용히 넘어간다. 위 오른쪽 🔊 버튼으로 끈다. mp3는 저장소에 올리지 않는다(Suno 결과물은 각자 받아 넣는다).

시제품의 한계:
- 영업 확률, 탁송 보상, 구매 가격, 포기 수수료는 PRD에 없는 예시 값이다.
- 시설(주유소·보험사·세차장)은 마을 그림에만 있고 규칙은 없다. 마을이 한 장이라 가게 레벨이 올라도 본관·주차장 그림은 안 바뀌고, 잠긴 칸에 「확장 예정」 표시만 한다.
- 마을 사람과 르르르는 정해진 길을 오가는 장식이다. 서로 비켜 서지는 않는다.
- 앱 코드나 저장 계약과 연결되지 않은 디자인 확인용이다.
- 연출은 React 18.3.1·Babel standalone 7.24.7을 CDN에서 받아 브라우저에서 변환한다. 인터넷이 없으면 연출 없이 기존 결과 창이 뜬다.
- 가게 확장 연출의 맵은 Claude Design의 임시 그림이며 우리 지도가 아니다.
- 브라우저는 사용자가 한 번 누르기 전엔 소리를 내지 못해서, 시작화면을 누른 뒤부터 소리가 난다. 효과음은 합성음이라 실제 효과음 파일이 오면 `template.html`의 `SFX` 표만 바꾸면 된다.
- 나머지 연출(4차 요청서 2-4절)은 아직 시안이 없다. 탁송 연출의 수익 탁송 손님 차는 주차 칸이 아니라 왼쪽 도로에서 들어오고, 사람끼리 비켜 서기·트럭 스프라이트 시트 내보내기는 넣지 않았다.
- 시작화면의 「르르르」 이름은 #19 권리 확인 전이라 글자로만 넣었다(공식 캐릭터 그림 없음). 이름은 `template.html`의 `GAME_TITLE` 한 줄에서 바꾼다. 가로 화면 기준이라 세로 휴대폰에서는 장면이 가운데 띠로 보인다.

## 다시 만들기

Python 3과 Pillow가 필요하다. 시제품은 `../town-preview/assets/`의 그림을 읽으므로 그 폴더가 있어야 한다.

```bash
cd docs/design-assets/pixel-kit
python3 prototype/build.py
```
