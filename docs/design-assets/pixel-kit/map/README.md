# 가게 지도 (호열 몫 ①)

`make_map.py`가 **2차 시안 A의 배치와 바닥 생김새**를 공용 32색 팔레트·32×16 쿼터뷰 타일로 옮겨 그린다. 본관은 위쪽에서 정면이 주차장·도로를 향하고, 도로와 주차장은 같은 아스팔트에 흰 주차선·모래색 보도·노란 점선이다. 고치고 싶으면 파일 위쪽 「배치」 숫자를 바꾸고 `python3 make_map.py`를 다시 실행한다.

| 파일 | 내용 |
|---|---|
| `ground.png` | 지도 바닥(640×464 원본): 풀밭·숲 바닥·도로·주차장 10칸·본관 터·시설 터 3곳 |
| `cover_lv1.png` ~ `cover_lv3.png` | 아직 안 열린 칸을 덮는 층(투명 배경). 가게 Lv1/2/3일 때 바닥 위에 얹는다. Lv4는 덮개 없음 |
| `slots.csv` | 주차 칸 10개의 바닥 중심 좌표(원본 기준), 열리는 레벨, 차가 바라볼 방향(두 줄 모두 가운데 통로를 봄: 본관 쪽 `sw`, 도로 쪽 `ne`) |
| `lots.csv` | 본관·주유소·보험·세차장 터의 바닥 중심 좌표와 크기(타일 수) |
| `preview_lv1~4@2x.png`, `preview_levels.png` | 참고 차량을 열린 칸에 놓아 본 확인용 합성 |

## 그리는 순서 (앱)

1. `ground.png`
2. 현재 레벨의 `cover_lvN.png` (Lv4면 생략)
3. 본관·시설 건물: `lots.csv` 좌표에 바닥 중심을 맞춘다
4. 차·사람·소품: 화면 아래쪽(y가 큰 것)부터 나중에 그린다

## 레벨별 열리는 칸 (PRD: 3/5/7/10칸)

| 레벨 | 열린 칸 |
|---|---|
| Lv1 | 0, 1, 2 |
| Lv2 | 0~4 (본관 쪽 줄 전부) |
| Lv3 | 0~6 (도로 쪽 줄 5, 6 추가) |
| Lv4 | 0~9 |

- 지도 원본 크기: 640×464, 앱은 2배(1280×928)로 그린다.
- 처음 정한 480×320에는 주차장 10칸과 시설 터 3곳이 함께 들어가지 않아서 크기를 바꿨다.
- 나무·가로등·화단 같은 소품은 경민(#171)이 그리므로 바닥에는 넣지 않았다.
