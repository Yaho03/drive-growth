# 차량 조사 자료 정리

정리일: 2026-11-03 (KST). 상태: 기존 조사 이관 완료 / 전체 목록 대조·외형·권리 확인 미완료.

## 1. 원본과 조사 범위

사용자가 지정한 조사 원본은 **이 채팅의 직전 현대자동차 차종 조사 답변**이다. 별도 차종 조사 파일은 최초 확인 시 프로젝트에 없었으며, 사용자 확인 후 채팅 자료를 이관했다. 전체 차종을 새로 조사하지 않았다.

게임 원본은 업데이트된 게임 기획서(원본 PDF는 로컬 보관·GitHub 게시 제외) 2026-11-03판, 8쪽이다. 확인한 SHA-256은 `ed3e5a08d92d69ab6e46505fdf9e054992b14e1a32bf9b270ae628dc8eaf5ceb`이다. 처음 읽은 2026-11-02판 5쪽 PDF는 사용자가 작업 도중 새 파일로 교체했다. 이 작업에서는 원본 PDF를 편집·삭제하지 않는다.

| 기준 | 범위 |
|---|---|
| 브랜드 | 현대 중심. 제네시스는 별도 브랜드 참고 기록 |
| 국가·시장 | 대한민국 국내 판매 라인업을 대상으로 한 선행 조사 |
| 현행 | 선행 조사일 2026-11-03에 공식 사이트에 등재된 것으로 기록한 모델. 이번 작업에서 모든 페이지를 재조회한 것은 아님 |
| 단종·해외 전용 | 조사 대상에서 제외. 미등재를 곧 단종으로 단정하지 않음 |
| 콘셉트·발표만 한 모델 | 판매 목록에 합치지 않음. 선행 조사에서 언급한 GV90은 이관 목록에서 제외 |
| 파생형 | N, 전기, 용도별 밴·상용차 등 원조사의 구분을 유지. 모든 트림을 분리한 목록이 아님 |
| 게임 범위와 차이 | 조사에는 상용차가 있지만 새 PDF 4쪽은 상용차를 일단 제외. 조사에 있다는 이유로 게임에 넣지 않음 |

**현대차 전체 목록으로 확정하지 않는다.** 시장·시점·세대·파생형 단위를 통일한 공식 전체 목록 대조는 미완료다.

## 2. 유일한 차종 목록

사실 자료는 [data/vehicles.csv](data/vehicles.csv)에서만 관리한다. 54개 **기록**(현대 42, 제네시스 12)이며, 기본 모델과 파생형이 섞여 있으므로 54개 독립 차종을 의미하지 않는다. 문서와 게임 단계표에는 차종 목록을 다시 복제하지 않고 `vehicle_id`로 참조한다.

- UTF-8 BOM CSV. 한 행은 조사 관리 단위이며 판매 SKU 또는 게임 단계가 아니다.
- 하이브리드·전기를 묶은 행과 별도 파생형 행이 공존하는 것은 원조사의 단위를 보존한 결과다. 정밀 모델 제작 전 필요할 때만 분리한다.
- 현재 식별자는 조사상의 안정적인 이름이다. 세대별 콘텐츠가 필요하면 기존 ID를 지우지 않고 세대별 ID와 상위 모델 관계를 설계한다.
- 빈 셀은 **자료 없음/미확인**이다. 해당 사양·자료가 존재하지 않는다는 뜻이 아니다.
- 게임 가격·희귀도·공격력·경험치·해금 레벨은 사실 CSV에 넣지 않는다.

### 필드와 판정 기준

| 필드 | 의미 |
|---|---|
| `vehicle_id`, `brand`, `market`, `model_name` | 공통 식별자와 기본 분류 |
| `generation`, `model_year` | 세대·연식. 원조사에 없으면 비움 |
| `body_type`, `market_segment`, `powertrain` | 차체·통상 차급·기존 동력 분류. 법적 차종이나 모든 트림 지원을 보장하지 않음 |
| `variant_notes`, `listing_scope` | 묶은 파생형, 조사 당시 등재 범위 |
| `exterior_features` | 출처로 확인한 외형 특징만 기재. 현재 미확인으로 비워 둠 |
| `fact_source_urls`, `source_checked_on`, `evidence_basis` | 공식 근거 URL, 선행/추가 확인일, 직접 재확인 여부 |
| `confirmed_fields`, `verification_status`, `open_questions` | 확인한 범위와 남은 확인. 행 전체 완료와 일부 필드 완료를 구분 |
| `image_source_url`, `logo_source_url`, `model_3d_source_url` | 자료를 찾은 위치. 파일 자체와 허가를 얻었다는 뜻이 아님 |
| `asset_license_url`, `asset_usage_status` | 사용 조건 원문 및 판정. 미확인 자산은 배포에 사용하지 않음 |

현재 모든 행은 세대·외형·권리 등 남은 확인이 있어 `추가 확인 필요`다. 캐스퍼 행은 2027 표기·가솔린·경차 안내를 이번 작업에서 재확인했지만, 해당 필드 확인을 전체 행의 완료로 승격하지 않았다. 나머지 행의 확인일은 **선행 조사에서 물려받은 확인일**이며 이번 작업의 전수 검증일이 아니다.

## 3. 오류·중복·불명확한 부분 처리

| 항목 | 정리 결과 | 남은 일 |
|---|---|---|
| 차체와 동력 혼재 | SUV·세단과 전기·하이브리드를 별도 필드로 분리 | 실제 제작할 파생형의 외형 차이 확인 |
| 캐스퍼와 일렉트릭 | 경형 가솔린과 소형 전기차를 별도 ID로 유지 | 동일 외형의 색상 스킨처럼 취급하지 않기 |
| N / N Line / 캘리그래피 | 고성능 모델·스포티 구성·트림은 같은 단위가 아님 | PDF의 가챠 풀을 모델·트림·색상으로 분리할지 팀 결정 |
| 스타리아 | 용도별 6개 기록 유지 | 게임의 ‘스타리아’ 단계에 어떤 파생형을 대표로 쓸지 결정 |
| 제네시스 | 브랜드이며 차종명이 아님 | 최종 단계의 대표 모델과 G70/G80/G90 관계 결정 |
| ‘전체 차종’, ‘19단계’ | 원안의 기획 표현일 뿐 조사 완전성 또는 확정 단계 수가 아님 | 프롤로그·탈것·차량·브랜드 단위 통일 후 단계 수 확정 |
| ‘가격순’ | 가격은 트림·동력·세금·시점에 따라 달라 단일 서열로 확정하지 않음 | 가격을 게임 능력치·보상·안전점수에 자동 연결하지 않기 |
| 베뉴 판매 여부 | 선행 공식 라인업에 등재된 것으로 조사됨 | 게임 자산 선정 시 최신 판매 상태·연식 확인 |
| 투싼 연료·아반떼 구형 자료 | 구형 디젤/LPi 근거를 현행 세대로 자동 합치지 않음 | 채택 세대의 공식 카탈로그만 확인 |

이번 추가 조회는 대표 후보 캐스퍼의 모델 표기와 자산 권리 안내의 누락 확인에 한정했다.

- [캐스퍼 공식 소개](https://casper.hyundai.com/vehicles/highlight): 2026-11-03 직접 확인. 2027 모델·가솔린 엔진·경차 혜택 표기 확인. 외형을 관찰·검수한 결과는 아님.
- [캐스퍼 일렉트릭 공식 설명](https://www.hyundaimotorgroup.com/ko/story/CONT0000000000159422): 선행 조사 출처. 가솔린과 크기·차급 차이의 근거.
- 나머지 행의 출처는 CSV에 보관한다. 상세 사양이나 세대가 필요한 후보만 공식 카탈로그로 추가 확인한다.

## 4. 이미지·로고·3D 모델의 사용 조건

기존 로컬 자료에 차량별 배포 허가가 붙은 사진·로고·3D 모델 묶음은 확인되지 않았다. 현재 앱의 도형은 별도 작업자가 만든 임시 표현이며 실제 차종의 공식 자산으로 판정하지 않는다.

| 자료 | 출처·확인 | 사용 판단 |
|---|---|---|
| 캐스퍼 사진 | 공식 소개 페이지 위치만 확인 | 게임 복제·가공·재배포 허가 미확인 |
| 현대·제네시스 로고 | 이번 이관에서 개별 원본과 사용 조건 미확보 | 사용 가능으로 판정하지 않음 |
| 차량 3D 모델 | 기존 자료에 없음 | 새로 생성하거나 수집하지 않음 |
| 공모전 제공 아트 묶음 | 개발 환경·참가 규정에서 해당 묶음과 허가 문구를 확보하지 못함 | 제공되지 않는다고 단정하지 않고 운영 자료 확인 필요 |
| 르르르 | 새 PDF가 명칭·설정과 사용권 확인 필요를 기록 | 공식 설정과 게임 설정 구분; 이미지·캐릭터 사용권 미확인 |

[공모전 약관](https://appdevchallenge.auto-hmg.io/terms) 제7조는 출품 구성요소의 적법한 사용 권한 확보를 요구한다. [개발 환경](https://appdevchallenge.auto-hmg.io/guide/development)과 [참가 규정](https://appdevchallenge.auto-hmg.io/guide/rules)을 함께 2026-11-03 확인했으나, SDK 제공이 차량 아트·로고 재배포 허가라는 근거는 찾지 못했다.

실제 자산 선정 시 파일·제공자·원문 조건·버전·확인일을 기록하고, 수정/상업적 사용/공모전 제출/APK 포함/공개 저장소/시연 영상/행사 전시 범위와 출처표기 의무를 각각 확인한다. 직접 그리거나 생성한 실차 외형도 자동으로 권리 확인이 끝난 것으로 보지 않는다. 이번에는 다운로드·자산 제작·문의 발송을 하지 않았다.

## 5. 다음 확인 순서

1. 게임의 대표 차종과 적용 세대·연식·트림 선정.
2. 해당 차종 하나의 외형 구분점(전면·측면·후면)을 공식 자료로 확인하고 CSV 갱신.
3. 제공 자산·가이드와 배포 범위 확인.
4. 한 차종으로 화면·성장 연출을 검토한 뒤 다음 차종을 추가.
5. 실제 게임 채택 목록과 국내 조사 목록의 차이를 단계 참조로 관리.

게임 역할·단계 연결·미결정 사항은 [01_PRD.md](01_PRD.md)를 따른다. 조사 정리는 디자인·구현·실차 검증 완료가 아니다.
