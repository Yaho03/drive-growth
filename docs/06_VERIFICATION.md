## 최초 게시와 검증 범위

2026-11-03 사용자가 문서·기본 설정 업로드와 `main` 머지를 명시적으로 요청했다. 별도 팀원 승인은 받지 않았으며 이번 초기 게시의 리뷰 예외로 PR에 기록한다. 향후 일반 변경의 사람 리뷰 원칙은 유지한다. 원격 검사와 머지의 실제 결과는 해당 PR·커밋·Actions 실행 기록을 근거로 한다.

아래 앱 관련 결과는 이전 로컬 작업의 시점별 기록이다. 현재 작업 공간에서 개발이 계속되고 있으므로 최신 구현 상태나 이번 원격 게시의 재현 결과로 해석하지 않는다. 이번 게시 검증은 게시 대상 파일만 분리한 상태에서 문서·링크·설정 검사를 수행한다.

`repository-checks`는 필수 파일과 로컬 Markdown 링크를 확인한다. 이 검사는 제품 동작이나 워크플로의 원격 성공을 증명하지 않는다. `android-checks`는 핵심 테스트·APK 빌드·Android Lint를 실행하도록 정의했다. 이번 게시에는 앱·핵심 소스가 없으므로 Android 검사는 명시적으로 생략한다. 소스가 어느 한 모듈에라도 추가되면 실행하며 실패를 숨기지 않는다.

## 실제 앱 시연의 완료 조건

아래는 예정 절차이며 시연 성공 기록이 아니다.

1. APK 설치·실행 → 데이터 출처와 주차 여부가 표시된다.
2. 유효 주행 입력 → 자동 기록으로 전환되고 게임 조작이 제한된다.
3. D 상태에서 속도 0 → 정산·조작 허용으로 잘못 전환되지 않는다.
4. 주차 확인 → 같은 주행에 대해 결과·보상을 한 번만 저장한다.
5. 앱 종료·재실행 → 결과와 성장 상태가 유지되고 중복 보상이 없다.
6. 누락·권한 거부·미지원 신호 → 안내하며 실제 기록을 만들어내지 않는다.
7. 확정된 추가 기능 → 성공·실패·재실행 결과를 각각 확인한다.

모의 시연은 영상과 앱에 모의 입력임을 표시한다. 에뮬레이터 차량 신호 수신과 실제 차량 실행은 따로 기록한다.
