# 시작 화면 제목 글꼴

Black Han Sans Regular는 원본 HTML 시작 화면의 제목에 쓰인 글꼴이다. 앱은 공식 배포본을 수정 없이 포함하며 시작 화면에서 로컬 파일로 읽는다.

- 배포본은 [Google Fonts 저장소](https://github.com/google/fonts/tree/f8c3ffd0ba0a07b052758dfb419fa10ec228998f/ofl/blackhansans)의 `BlackHanSans-Regular.ttf`다.
- SHA-256은 `31960809284026681774a8e52dc19ebcad26cf69b0ad9d560f288296fbb52739`다.
- 저작권 고지와 SIL Open Font License 1.1은 [OFL.txt](OFL.txt)에 포함한다.
