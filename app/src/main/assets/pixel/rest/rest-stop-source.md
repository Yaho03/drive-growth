# 휴게소 수면 연출

르르르판과 담요판 WebP는 PR #296의 `394369aec8612a53f4070e4219f6fcbd7da4ec79`에서 가져왔다. 원본은 #295의 340×237 픽셀 보드다. 첫 재생 6초, 운전석 반복 10초, 움직임 줄이기용 숨쉬기 10초를 사용한다. #298에선 담요판을 채택했다. 2026-11-14 사용자가 이 휴게소 르르르판 사용 허가를 확인해, 기존 르르르판 원본 3개를 Android 화면에서 사용한다. 별도의 원본 허가 문서는 이 변경에서 확인하지 않았다.

| 르르르판 파일 | SHA-256 |
|---|---|
| `rururu-intro.webp` | `47b0115086061a20fd2ca50966eeae73c00398e9cad0696ae4ae1631fa43ec6d` |
| `rururu-loop.webp` | `512dacca3361137db23ae73f05e714afcc81783a3765b4e6fc5b8d29f5fe737c` |
| `rururu-still.webp` | `3be40c5892da4fd22fbc780598ced74e40715bed48a2ba92c3aa2163df19f4e7` |

`blanket-*-sound.pcm`은 PR #295 `818234ebaa1c44a270f575a140bfaf910d1c96b9`의 `rest-stop-sound.js`를 OfflineAudioContext에서 재즈를 끄고 추출한 22,050Hz 스테레오 16비트 LE PCM이다. 원본의 빗소리·와이퍼·차량 통과·숨소리·장식 소리를 사용했다. 전환점에 12ms 감쇠를 적용했다. 브금은 앱의 기존 `bgm/rest.mp3`에서 재생한다.

합성 효과는 장면 시간과 움직임 줄이기 설정을 사용한다. 두 영상판의 같은 단계에 기존 PCM을 공통으로 적용한다. 파일명은 최초 이식 당시의 이름이다.
