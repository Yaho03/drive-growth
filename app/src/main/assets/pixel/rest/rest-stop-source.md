# 휴게소 수면 연출

담요판 WebP는 PR #296의 `394369aec8612a53f4070e4219f6fcbd7da4ec79`에서 가져왔다. 원본은 #295의 340×237 픽셀 보드다. 첫 재생 6초, 운전석 반복 10초, 움직임 줄이기용 숨쉬기 10초를 사용한다. `rururu-*.webp`는 같은 보드의 르르르판으로 #296 `394369a`에서 가져왔다. 2026-11-14 사용자 결정으로 앱은 르르르판을 재생한다(`RestStopMotionView.VARIANT`). 출품 권리는 #29에서 확인하며, 거절되면 담요판으로 바꾼다. 효과음 PCM은 두 판에 같이 쓴다.

`blanket-*-sound.pcm`은 PR #295 `818234ebaa1c44a270f575a140bfaf910d1c96b9`의 `rest-stop-sound.js`를 OfflineAudioContext에서 재즈를 끄고 추출한 22,050Hz 스테레오 16비트 LE PCM이다. 원본의 빗소리·와이퍼·차량 통과·숨소리·장식 소리를 사용했다. 전환점에 12ms 감쇠를 적용했다. 브금은 앱의 기존 `bgm/rest.mp3`에서 재생한다.
