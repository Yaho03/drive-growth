# 탁송 트럭 레이어

사용자 제공 `1-prototype.html`의 `delivery.jsx` 원본에서 내보낸 투명 132×72 PNG다.
첨부 SHA-256은 `5e33b8ca3c97b066148e6a5795d2131528028e9406b60e69ca348a6ddfe74d34`다.
원본의 `DV.tSVG(DV.TBODY…)`를 브라우저 Canvas로 래스터화했다.
차체, 바퀴 두 프레임, 적재판, 적재판 난간, 운전석, 줄무늬, 경광등 두 프레임, 고정띠 순으로 합성에 사용한다.
고정띠는 흰색으로 내보내며 Android가 차량 등급 색을 적용한다.
